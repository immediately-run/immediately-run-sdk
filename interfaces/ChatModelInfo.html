Interface ChatModelInfo

One chat model a connected provider offers, described per model (R3-1122): what a picker sizes itself by. The host sends it as an object entry of a choice's wire models list. It crosses only complete and rebuilt: an entry missing a required field, or carrying one of the wrong type, is not described at all (its id still joins ChatProviderChoice.models), and a key not declared here never crosses. Names, ids, features and prices only — never keys, usage or balance.
