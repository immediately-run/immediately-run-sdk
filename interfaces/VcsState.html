OptionalopenPR

openPR?: null | { number: number; url: string }

The open pull request whose head is the loaded branch, projected host-side. On the snapshot, not on branch, because branch is null when no sidecar names the branch (another device), which is exactly when this is needed. null means known: none open; absent means an older host that does not say. prs lists every PR the host polled; this names the one whose head is the working branch.
