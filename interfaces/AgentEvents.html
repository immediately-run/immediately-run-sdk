OptionalonCompact

  • onCompact(
        info: {
            cacheReadTokens?: number;
            cacheWriteTokens?: number;
            summarizedCount: number;
        },
    ): void

    Fired when the loop compacts the transcript to stay under the context window; summarizedCount is how many older messages were folded into the summary.

    R3-336: a compaction invalidates the conversation-prefix cache it rewrote — the durable system+tools prefix survives it — so the next turn pays one prefix re-write. cacheReadTokens/cacheWriteTokens are the run totals AT the compaction, which is what lets the cost curve across it be read off rather than assumed (exit 2).

    Parameters

    • info: { cacheReadTokens?: number; cacheWriteTokens?: number; summarizedCount: number }

    Returns void
